# John Melbert Lanuza — Personal Portfolio

A personal, mobile-friendly portfolio website by **John Melbert Lanuza**, Bachelor of Science in Information Technology student at Laguna State Polytechnic University (Siniloan Campus).

## What's inside

- `index.html` — Home, About, Skills, Projects, Education and Contact sections
- `style.css` — Responsive, dark navy and blue styling

This is a **static website** and can be hosted through **GitHub Pages**. It links to the separate [Student Management System source repository](https://github.com/johnmelbertlanuza013-maker/StudentManagementSystem), which uses React, Express, Prisma ORM and MySQL.

## How to view locally

Open `index.html` in any modern browser. No installation is required.

## Publishing with GitHub Pages

1. In this repository, open **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Choose **main** and **/(root)**, then select **Save**.
4. Once GitHub finishes deployment, the expected URL is:
   `https://johnmelbertlanuza013-maker.github.io/John-Melbert-Lanuza-Portfolio/`

The separate Student Management System's backend cannot run on GitHub Pages. Its database must run on a separate server or locally.
